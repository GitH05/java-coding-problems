🔐 File Encrypter

A simple Java + MySQL application for securely storing, hiding, and restoring files.

Users can sign up and log in using email OTP verification, then manage their files through a simple command-line interface.

✨ Features

📧 Email OTP verification for Sign Up & Login

🔐 Hide and store files

👀 View hidden files

♻️ Restore files to their original location

🗄️ MySQL database storage

👤 User-specific file management

🔄 How It Works
Sign Up
   ↓
Email OTP Verification
   ↓
Login
   ↓
Email OTP Verification
   ↓
File Management
   ├── Show Hidden Files
   ├── Hide File
   └── Unhide File

🛠️ Technologies

Java

MySQL

Java File Handling

📋 Menu
1 → Show Hidden Files
2 → Hide a File
3 → Unhide a File
0 → Exit

💡 Project Idea

File Encrypter allows users to keep their files away from their normal file location by storing their file data in a database.

Users can later restore their files to the original location whenever needed.

Hide it. Store it. Restore it.
